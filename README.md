# 🌐 Personal Portfolio Website

This is a personal **Portfolio Website** built using HTML, CSS, JavaScript, and Django .  
It showcases skills, projects, achievements, and contact information in a clean and modern layout.

🌍 **Live Deployment:**  
👉 https://sanjaypoozhikkuth.pythonanywhere.com/

---

## 🎯 Purpose of This Project

This portfolio is designed to:

- Present your skills and experience  
- Showcase your projects with GitHub links  
- Provide a professional online presence  
- Make it easy for recruiters, clients, and collaborators to contact you  

---

## ✨ Features

- Clean and responsive UI  
- About Me section  
- Skills section  
- Projects showcase  
- Contact form / details  
- Smooth navigation  
- Deployed on PythonAnywhere  
- Easy to update and customize

   ```bash

   cd portfolio
   
2.Install Django (if backend is used)
  pip install django
  
3.Run the server
  python manage.py runserver

4.Open your browser
  http://127.0.0.1:8000/
